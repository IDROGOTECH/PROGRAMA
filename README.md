# IDROGOTECH - Plataforma Digital de Ingeniería y Arquitectura

Desarrollado para la distribución y venta de material digital especializado (manuales, planos, plantillas, guías técnicas).

## Requisitos previos
- Node.js instalado en el sistema.

## Instrucciones de instalación y ejecución
1. Abrir la terminal en la carpeta del proyecto.
2. Instalar las dependencias con:
   ```bash
   npm install
   ```
3. Ejecutar el servidor backend:
   ```bash
   npm start
   ```
4. Abrir en el navegador: `http://localhost:3000`

## Estructura del Proyecto (Visual Studio Code)
- `public/`: Archivos HTML, CSS, JavaScript y recursos estáticos (`assets/img/`).
- `src/`: Lógica del servidor Node.js y rutas protegidas.
- `database/`: Esquemas de base de datos.
